# 参考基准点

在实现或验收一张对照已批准图像的匹配之前先读。

1. **先度量参考。** 为每个要求的关系挑选可见锚点：字形边界、线段端点、图标边缘、实心剪影。记录一张小表：特征 | 参考关系/范围 | 候选测量 | 差值 | 通过/修复/不确定。改代码之前先填参考列；绝不从最新的候选反向校准目标。
2. **区分核心与边缘。** 柔和的边缘没有单一边界。定位每一侧的暗/不透明核心、它的过渡带和微弱的外侧尾巴。说明前景笔画在何处接入这个轮廓。"全宽"可能指可见核心，而不是模糊的每个像素；在把简写翻译成百分比或硬裁剪之前，先对照提供的图像消歧。例如，把一条线的两端同时与文字边界和淡出比较，并把最后一个字形到线之间的间距与线以下的尾巴分开比较。
3. **保持比例诚实。** 按应用的真实比例保存原始截图，记录 viewport 和 DPR。生成的参考若光栅尺寸不同，记录它与其来源截图的映射；未知时，与字形高度等稳定基准点比较比值，并声明不确定性。给任何派生的对齐图贴标签。绝不仅仅为了让两者一致而缩放应用、排版或证据。原生截图始终是证据本体。
4. **隔离含糊的效果。** 当地形、纹理或光照可能被误认为阴影时，对同一个冻结状态截两次图，只切换那个效果。用差值定位它的贡献；把正常截图放在旁边。横跨一条边使用局部对比/衰减采样，而不是全图相似度。若不存在干净的参考基线，报告推断的范围，而不是编造一个精确的不透明度或端点。
5. **让整个特征待在裁剪里。** 包含两个端点、所有淡出尾巴和周围上下文。每次几何变化后复查裁剪边界；一张旧裁剪可能藏住新延伸的边缘。放大裁剪是原生尺寸证据的补充，绝不是替代。
6. **闭合每一处分歧。** 评审者说"稍微宽了""有个小缝"或"范围不确定"，就等于指出了尚未完成的对比工作。度量并解决它，或记录一个已证实的光栅化极限或用户批准的偏差。不要因为整体图像看起来不错就把这些话转成通过。用这些参考关系校验测试断言，而不是某个方便的 CSS 机制或上一次的口头解读。

在用户抓到一处遗漏的细节之后，重新审视整张基准点表。修复之后复查相邻项：恢复一条亮线可能抹掉它上方的暗色支撑；延长那条线又可能越过参考的淡出边缘。以更新后的表和当前截图收尾，而不是重复一遍笼统的结论。
