# 移交规格说明

我要把这份规格说明的工作移到另一台机器或另一个智能体上。下一个会话**冷启动**：它只有仓库，别的什么都没有。它没有这场对话、没有这台机器上的文件、也没有你的记忆。把规格说明留好，让那个会话能像它一直在场一样继续。

从讨论和工作本身收集本次会话知道、而规格说明尚未写明的东西，写进规格说明：

- 什么已完成、什么做了一半且确切停在哪里、接下来是什么；
- 我一路决定或纠正了什么，以及我希望这项工作如何完成；
- 我沉默时你做出的决定，以及仍在等我的一切；
- 已知损坏或未经验证的东西，连同你已查明的情况；
- 只活在这台机器上、而下一个会话需要的一切：未推送的分支、未提交的工作、值得保留的临时结果。

把这些写进规格说明自己的移交部分，就地更新：规格说明保持为一份当前状态的记述，而不是一份顶上贴了张新便签的记录抄本。然后推送，使规格说明指向的一切都存在于远端。

当一个全新的智能体仅凭仓库就会选出与你相同的下一步、且不会重复问我已回答过的问题时，即告完成。
