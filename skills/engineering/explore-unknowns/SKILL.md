# 探索未知

地图不是疆域。提示、计划和上下文窗口是地图；代码库、领域和用户的真实意图是疆域。两者之间的差就是未知事项——一个未知在写代码之前发现只花几分钟，而同一个未知在三个 PR 之后才发现，代价就是那三个 PR。

本技能是一场引导式对话：**象限漫步**。你与用户一起填出任务的四象限地图，每个阶段一个象限，最后用户带着完成的地图离开。地图就是交付物；实现是另一个任务，只在地图交付之后才开始。

每个阶段都适用两个动作：

- **反应胜过想象。** 当你能递给用户一个具体的东西去反应时——一个渲染出的选项、一个可点击的 mock、一张决策表——绝不要让用户凭空描述他们想要什么。反应能提取出用户拥有、却无法在无人提示时说出的知识。
- **每个产物都组装出回复。** 以预拟好的用户下一条消息收尾每个产物：拿走/跳过胶囊、共鸣复选框、一张决策表、一段可复制的锐化提示——让用户的反应几乎零打字地变成下一条消息。

## 象限漫步

五个阶段，按序行进，一次一个。**进入一个阶段时，阅读它的参考文件并遵循之。** 行进过程中随时报出当前象限——用户应始终知道自己站在地图的哪个位置——并在你面前完成当前阶段后才开启下一个。

1. **[已知之已知](references/stage-1-known-knowns.md)**——扫描疆域，然后以已定之地开场。
2. **[已知之未知](references/stage-2-known-unknowns.md)**——你说得出名字的问题；逐个解决。
3. **[未知之已知](references/stage-3-unknown-knowns.md)**——提取无人诉诸言语的品味与隐性上下文。
4. **[未知之未知](references/stage-4-unknown-unknowns.md)**——扫荡疆域寻找地雷。
5. **[交出地图](references/stage-5-hand-over-the-map.md)**——完成的四象限地图，漫步唯一的完成条件。

当用户继续去构建、评审或合并漫步所映射的东西时，阅读[漫步之后](references/after-the-walk.md)——地图在规划结束之后继续活着。

## 偏好检查点——主动提出代为回答

统计用户在整个漫步中已回答的问题数，而不是轮次数，也不是从疆域里找到的答案数。大约五六个之后，如果他们的偏好已形成清晰模式且仍有问题待问，为这个检查点暂停访谈。如果模式仍不清晰，继续有针对性的提问，待清晰后再提出；不要为了凑数而制造问题。

1. 列出你从其回答中推断出的偏好（扎根于他们的回答），并欢迎纠正。询问由你代答相符的问题是否有帮助：**确认或修改这些偏好并选择加入，或继续由自己作答**。这将取代下一个访谈问题。
2. 等待明确的选择加入。仅确认偏好并不构成委托的同意；沉默也不是同意。如果他们只确认了偏好，就把委托选项澄清一次，之后若问题仍未被回答则默认回到访谈。如果他们拒绝，就继续下去，不再反复提议。
3. 一旦加入，就回答那些答案能从已确认偏好中清晰推出、且在其委托范围之内的问题。偏好相互冲突、或新的取舍超出该范围时，问用户。缺失的事实先去疆域里调查；只有疆域无法解决时才发问。偏好不能替代关于疆域的事实。
4. 每给出一个代答就同步披露：**问题 → 答案 → 偏好与理由**，标注**由智能体代你回答**。小批量没有问题；绝不能把不同的问题合并成一个隐藏的决定。每条条目都带着该署名进入地图，而不是暗示用户亲自作答。欢迎纠正，但不要求对每个答案逐一批准。
5. 立即服从纠正与撤回。纠正会更新偏好摘要，并重开被其推翻的决定。撤回会终止未来的代答；此前的答案保留其署名，除非用户要求重新审视。委托只对本次漫步有效，既不授权实现，也不跳过剩余象限。

**完成条件**：用户已就是否委托做出选择，且如果已加入，已确认的偏好和委托范围已记录在地图决策台账之旁。

## 规则

- 按序走象限，一次一个阶段，随时报出当前象限。漫步以地图交到用户手中而告终——没有地图，就没有完成。
- 阶段为漫步排序，但绝不封锁信息。一项对正在进行的决策有实质影响的发现，在到手的那一刻就要披露，然后按其象限归档到地图上——绝不为等到其阶段排定的回合而扣住不发。
- 任何东西都不得在幕后关闭。地图记录为已关闭的任何问题或判断，必须先展示给用户——包括疆域自己回答的那些。
- 以决定而非讨论来关闭条目。每个已解决的未知都以一行决定加其理由收尾，措辞要让规格说明能原样作为既定前提携带。构建者日后在无人监督下发明的每一个选择，都是这次漫步漏掉的未知——一张把决策留给实现者的地图是不完整的。
- 关于疆域的主张要引用真实读过的文件；编造的数据要如实标注。一个捏造的细节会摧毁整张地图的权威。
- HTML 产物是自包含的单文件：内联 CSS/JS，无外部请求，用可信的假数据而不是 lorem ipsum。
- 在每个需要用户反应的阶段边界停下。绝不在未经确认的猜测上冲进实现——实现是另一个任务，在地图交付之后才开始。
