# 营销页面

这是一本规则手册，不是工作流：下面的每条规则既是构建时要遵守的约束，也是审计时要对照的检查项。先给页面归类——每个公开页面恰好属于一个**页面类别**，类别决定它的索引、链接、全站框架（chrome）与接线。

## 页面类别

| 类别 | 索引 | 可达性 | 全站框架 |
|---|---|---|---|
| **活动落地页** | `noindex, follow`；绝不进入 sitemap | 绝不从导航/页脚链接 | 极简：logo + 唯一一个 CTA，页脚仅法律条款，无站点导航 |
| **产品页** | 被索引 | 导航的 Product 区块和/或页脚 | 完整全站框架 |
| **SEO 树页面**（程序化：按人群、按行业、按竞品） | 被索引 | 页脚链接网格 + 中心页 | 完整全站框架 |
| **编辑内容**（博客/指南） | 被索引 | 页头 + 页脚 | 完整全站框架 |
| 法律/工具页 | 被索引 | 页脚 | 完整全站框架 |

- 一个既被 noindex 又无链接的页面是**僵尸页面**——把它提升为有链接、被索引的类别，或改成活动落地页。绝不留在半途状态。
- 活动落地页放在专属的 URL 前缀下（如 `/l/<slug>`）：一个 `startsWith` 就能同时覆盖全面 noindex 检查和"绝不进导航"检查，且 slug 与真实页面撞名变得不可能。

## 活动落地页规则

活动落地页是主落地页的替身——一类受众、一个承诺、付费流量。它们用 SEO 换取信息匹配的自由；被索引的近似重复页会分散权重，并冻结本应每天都能 A/B 的文案。

- **信息端到端匹配**：广告文案 → H1 → 注册后首屏，一个不断裂的承诺。在产品支持的情况下，活动标识符随注册流转进入引导流程与分析，使首次使用体验延续该承诺，且转化可按落地页归因。
- 一个 CTA，沿页面向下重复出现；旁边放社会证明；降低摩擦的微文案（"无需信用卡"）；只采集后续才用得上的信息（通常只要邮箱）。
- 静态文本/图片首屏主视觉——首屏不放全屏视频或重型 JS。在付费流量上，LCP 是转化的一项输入。
- 无法度量的落地页无法迭代：每落地页转化率（线索 → 注册 → 购买）必须在投放广告之前能在某处读到。
- 被砍掉的活动页面不做重定向：删除的路由返回 404，此后 Search Console 里的 404 正是想要看到的信号，不是缺陷。

## 被索引页面规则

以下每项在代码库中都有一个属主——去找当前属主，不要相信记忆中的路径：

- 该路由出现在站点门禁所对照的封闭式路由注册表中。
- 被索引 ⇔ 进 sitemap，要么都有要么都没有：sitemap 里的 noindex URL 是矛盾信号，被索引却缺席 sitemap 同样是。`lastmod` 要诚实（内容日期，不是构建时间）。
- 如果站点提供智能体可读表面（llms.txt、markdown 孪生文件），它们必须与页面渲染自同一份文案源——绝不从构建出的 HTML 渲染，绝不手工漂移出副本。
- robots 对 AI 爬虫放行经过审核的被索引树；只禁止活动落地页和内部表面。robots、meta robots 与 sitemap 对每个 URL 必须口径一致。
- 每个被索引页面都能从页头或页脚到达——页脚链接网格是爬取轨道。只能通过 sitemap 发现的页面会在"已发现——未编入索引"状态里滞留数周，且得不到任何内部权重。
- 产品事实（定价、限额、套餐名）源自产品代码所拥有的唯一来源——被重述的数字会悄悄漂移，而且什么都不会变红。
- 内部链接写路径，绝不写源（origin），这样封闭式检查才能验证每个写作目标都能解析。
- 带语言区域前缀、指向仅存在于单一语言区域的链接必须可解析（重定向到规范语言区域，而不是 404）——全站框架会从每个页面预取每条链接。
- 删除或重命名页面时，在同一个遍次里删除每处引用：路由注册表、sitemap、智能体可读孪生文件、保留页面的链接、视觉基线，以及 e2e/旅程锚点（grep 测试套件——让本地门禁保持绿色的重命名，可能在数小时后弄断线上旅程）。

## SEO 规则

- 从编辑内容指向核心商业页的正文内链接，比页脚锚点传递更多权重——在内容确实相关的地方添加。
- 对比/竞品页面要有诚实可见的更新日期，并按真实节奏刷新——挂着旧日期的页面比不标日期的更糟。
- 程序化树页面保持实质内容（具体的任务、具体的文案）——单薄的模板页是门页（doorway page）诱饵。
- 中心页的存在是为了让叶子继承权重：每片树叶子都从它的中心页获得链接，中心页则从全站框架获得链接。

## 视觉覆盖规则

- 可复用的区块和组件有一个隔离、确定的**夹具**（fixture，即 playground/storybook 条目），由它拥有其视觉覆盖；夹具菜单兼作组件目录，新页面由它组合而成。
- 每个模板只保留一个关键路由的整页代表性截图。路由会频繁变动；夹具才是稳定的检验基准。新模板 → 新增一个代表性路由；新区块 → 增加夹具，而不是更多路由截图。
- 视觉基线必须经过未受暗示的第二意见才能接受——被变更暗示过的眼睛会放过新鲜眼光能抓到的缺陷。

## 审计清查

审计站点 = 逐条评估上述所有规则，外加这些横切清查；每项清查结果必须为空或给出解释：

1. 僵尸页面（既 noindex 又无链接）。
2. sitemap/robots/meta 之间的不一致。
3. 活动落地页被任何被索引页面链接，或出现在 sitemap 中。
4. 从页头/页脚无法到达的被索引页面。
5. 在视觉覆盖体系中没有属主的组件。
6. 重述了已有规范属主的产品事实的营销文案。
7. 全站框架中跨语言区域失效的链接。
